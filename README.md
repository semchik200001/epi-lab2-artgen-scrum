# ARTGEN — корпоративный сайт (учебный проект)

Репозиторий лабораторной работы №2 по дисциплине «Экономика программной инженерии» (ИТМО).
Задачи проекта ведутся в YouTrack: проект **ART**, доска **ARTGEN Development**.

Содержимое формируется в ходе учебной симуляции Scrum: каждая задача получает ветку
с ID задачи, коммиты ссылаются на задачу, принятые задачи вливаются в `develop`.

## Ветки

| Ветка | Назначение |
|---|---|
| `main` | Выпущенные версии, теги `v0.1`, `v0.2`, … |
| `develop` | Сборка текущего инкремента |
| `feature/ART-<n>-<тема>` | Работа по задаче |
| `bugfix/ART-<n>-<тема>` | Исправление дефекта |
| `release/<версия>` | Подготовка выпуска |

## Каталоги

- `docs/` — требования, архитектура, управление проектом (Product Owner)
- `design/` — UI-kit и макеты
- `theme/` — фронтенд темы WordPress
- `platform/` — backend, CMS, CI/CD
- `tests/` — тест-планы и протоколы проверки
